<sub>01 / HOW I WORK</sub>

## 两个在研究的问题。

<table>
<tr>
<td width="50%" valign="top">

**个人 Agent**

一个 Agent 怎样真正长期陪着一个人：记得上下文、接得住任务、慢慢长出能力，而不只是一次性的对话。

</td>
<td width="50%" valign="top">

**基于 Agent 的交付方法论**

从需求、拆解、实现到上线运行，哪些环节交给 Agent，人该守住哪些判断，怎样让交付稳定、可复盘、可重复。

</td>
</tr>
</table>

**交付蓝图：人判断，Agent 执行，事实回写**

| 售前 | 需求 | 开发 | 验收 | 上线 |
| :---: | :---: | :---: | :---: | :---: |
| 听懂原话 | 写清做法 | 动手开发 | 测试验收 | 上线反馈 |

五个交付节点共用同一套事实与门禁，反馈回到下一轮需求：**需求有出处、任务有授权、变更有版本、验收有依据。**

[↗ 看团队怎么用](https://owenshen.top/agent/delivery) &nbsp;·&nbsp; [↗ 看个人怎么搭](https://owenshen.top/agent/personal)

研究的起点始终是具体场景：工作里反复要做的事，日语对话里没听懂的一句话，或者突然冒出的一个小念头。做出来的网页、桌面 App 和 iPhone 工具，既是产品，也是验证这些想法的实验。

有些尝试慢慢长成产品，有些还停在实验和笔记里。我想把这些过程都留下来。
